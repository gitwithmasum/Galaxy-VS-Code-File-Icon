# Changelog

## 1.3.0

- Expanded the icon pack from web development into **full-stack, database, AI/ML and DevOps** workflows.
- Added dedicated icons for **Prisma, PostgreSQL, MongoDB, Firebase, Jupyter Notebook, TensorFlow, PyTorch, ML model files, Vercel, Netlify, Kubernetes and CI/CD workflow files**.
- Added special Galaxy folders for **app, pages, routes, services, lib, config, database, prisma, models, AI/ML notebooks and workflows**.
- Added mappings for model artifacts including `.pt`, `.pth`, `.onnx`, `.pkl`, `.pickle`, `.joblib`, `.h5` and `.tflite`.
- Added mappings for common deployment/config files including `vercel.json`, `netlify.toml`, Firebase config, Prisma schema files and common Kubernetes manifests.
- Kept the same compact neon Galaxy visual language and 16px Explorer readability.

## 1.2.0

- Reworked the core icon set for much clearer **16px Explorer readability**.
- Replaced several small text-based symbols with stronger recognizable shapes for HTML, CSS, JavaScript, TypeScript, React, Python, JSON, Markdown, Git, npm and environment files.
- Polished the default file, folder and expanded-folder visuals to better match the approved **Masum Galaxy // File Icons** preview.
- Added dedicated folder icons for **src, components, assets, public, themes, icons, tests, api, utils, hooks, styles and .vscode**.
- Polished the existing **node_modules, Supabase and .github** folder icons.
- Added dedicated icons for **VSIX packages, LICENSE and CHANGELOG** files.
- Expanded folder aliases so common names such as `images`, `helpers`, `__tests__`, `static` and `css` automatically receive matching Galaxy folder icons.

## 1.1.0

- Expanded the **Masum Galaxy // File Icons** pack for modern web, app and backend development.
- Added dedicated galaxy-style icons for **Next.js, Vite, Tailwind CSS, Node.js, C, C++, Java, SQL, Docker, Supabase, GitHub, YAML, config files and lockfiles**.
- Added special folder icons for **Supabase**, **.github** and **node_modules**.
- Added mappings for common framework/config files including Next.js, Vite, Tailwind, Docker Compose, TypeScript/JavaScript config, ESLint, Prettier and environment files.
- Kept the established dark-space, cyan/violet neon visual language while giving each technology its own accent color.

## 1.0.0

- Initial **Masum Galaxy // File Icons** release.
- Added futuristic default file, folder and expanded-folder icons.
- Added mappings for HTML, CSS, JavaScript, TypeScript, React, Python, JSON, Markdown, Git, npm and environment files.
